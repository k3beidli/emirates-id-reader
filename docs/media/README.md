# README animation

`card-reader.webp` is the same animation used by the companion application's
waiting screen (`card-reader-clean.webp`). It loops continuously at 560 × 700
pixels and retains smooth, partially transparent edges without a background
shadow. The README displays it at 240 pixels wide.

The asset is animated WebP rather than GIF. It replaces the older GIF so the
README uses the same smooth transparency as the app. The source artwork uses a
sample card with placeholder identity values.

The original animation project and alpha WebM are maintained separately. They
are not required to build the SDK. This file is bundled in the SDK package so
the README image remains available in a source archive.
