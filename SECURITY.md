# Reporting security issues

Report vulnerabilities privately through
[GitHub's security advisory form](https://github.com/k3beidli/emirates-id-reader/security/advisories/new).
Do not open a public issue for an undisclosed vulnerability.

Include the affected version, reproduction steps, and likely impact. Use
synthetic examples; do not attach real cardholder data, card dumps, or credentials.

This project is experimental. Security fixes target the current development
version and latest release; older versions have no separate support commitment.

For application data handling, see [the security guide](docs/security.md).
